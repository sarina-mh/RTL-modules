How to design a datapathچگونه یک دیتاپدیت طراحی کنیم

A datapath is the part of a digital system that moves and transforms data: registers, multiplexers, arithmetic units, counters, memories, and the buses that connect them. The controller (FSM) tells the datapath what to do; the datapath performs it.

  1. Start from the algorithm. Write the pseudo-code, then list every operation and every value that must survive from one cycle to the next.
  2. Choose widths and number formats. Decide unsigned vs two's complement, fixed-point scaling, and the width of every bus. Widths propagate: a sum needs one extra bit; a product needs the sum of the operand widths.
  3. Allocate resources. Decide how many adders or multipliers you can afford, whether an ALU is shared, whether storage is a register file or individual registers, and whether the array lives in registers or RAM.
  4. Draw the block diagram. Label every wire with its width. Mark registers with a clock and enable. Keep combinational clouds (adders, muxes, comparators) separate from state.
  5. List the control signals. Mux selects, register enables, write enables, counter enables, and operation selects. These come from the FSM.
  6. List the status signals. Zero, carry, overflow, comparator results, counter terminal count, done, and busy. These go back to the FSM.
  7. Check timing. Find the longest register-to-register combinational path. If it is too slow, add pipeline registers or split the operation over multiple cycles.
  8. Parameterize. Make widths, depths, and array sizes parameters so the same RTL can be reused.
  9. Verify. Use directed tests for corner cases and random tests for coverage. Check reset, overflow, and boundary conditions.
Example: an accumulator is a register plus an adder plus a mux. Control: load enables the register. Status: zero and overflow. The FSM decides when to add and when to clear.

دیتاپدیت بخشی از یک سیستم دیجیتال است که داده را جابه‌جا و پردازش می‌کند: ثبات‌ها، مالتی‌پلکسرها، واحدهای حساب، شمارنده‌ها، حافظه‌ها و باس‌هایی که آن‌ها را به هم وصل می‌کنند. کنترلر (FSM) به دیتاپدیت می‌گوید چه کاری انجام دهد؛ دیتاپدیت آن را اجرا می‌کند.

  1. از الگوریتم شروع کن. شبه‌کد را بنویس، سپس هر عملیات و هر مقداری را که باید از یک کلاک به کلاک بعدی حفظ شود فهرست کن.
  2. عرض‌ها و فرمت اعداد را انتخاب کن. بدون علامت یا مکمل دو، مقیاس fixed-point و عرض هر باس را مشخص کن. عرض‌ها منتشر می‌شوند: جمع به یک بیت اضافه نیاز دارد و ضرب به مجموع عرض دو عملوند.
  3. منابع را تخصیص بده. تصمیم بگیر چند جمع‌کننده یا ضرب‌کننده داری، آیا ALU مشترک است، حافظه به‌صورت register file است یا ثبات‌های جدا، و آرایه در ثبات‌ها نگه داشته می‌شود یا RAM.
  4. بلوک‌دیاگرام بکش. عرض هر سیم را بنویس. ثبات‌ها را با کلاک و enable مشخص کن. منطق ترکیبی (جمع‌کننده، مالتی‌پلکسر، مقایسه‌کننده) را از حالت (state) جدا نگه دار.
  5. سیگنال‌های کنترل را فهرست کن. انتخاب مالتی‌پلکسر، enable ثبات، enable نوشتن، enable شمارنده و انتخاب عملیات. این‌ها از FSM می‌آیند.
  6. سیگنال‌های وضعیت را فهرست کن. صفر، رقم نقلی، سرریز، نتیجهٔ مقایسه، رسیدن شمارنده به مرز، done و busy. این‌ها به FSM برمی‌گردند.
  7. زمان‌بندی را بررسی کن. طولانی‌ترین مسیر ترکیبی بین دو ثبات را پیدا کن. اگر کند است، ثبات pipeline اضافه کن یا عملیات را روی چند کلاک بشکن.
  8. پارامتریک کن. عرض‌ها، عمق‌ها و اندازهٔ آرایه را پارامتر کن تا همان RTL قابل استفادهٔ مجدد باشد.
  9. تأیید کن. برای حالت‌های مرزی تست directed و برای پوشش تست random بنویس. ریست، سرریز و مرزها را بررسی کن.
مثال: یک accumulator از یک ثبات، یک جمع‌کننده و یک مالتی‌پلکسر تشکیل می‌شود. کنترل: load ثبات را فعال می‌کند. وضعیت: zero و overflow. FSM تصمیم می‌گیرد چه زمانی جمع و چه زمانی پاک‌سازی انجام شود.

How to design an FSMچگونه یک FSM طراحی کنیم

An FSM is the control unit of a sequential system. It remembers the current step in a state register and uses combinational logic to decide the next state and the outputs.

  1. List the states in words. For example: IDLE, SCAN, SWAP, DONE.
  2. List the events and transitions. Which input or condition moves the machine from one state to another?
  3. Choose Moore or Mealy. Moore outputs depend only on the state (safer, easier to debug). Mealy outputs depend on state and inputs (faster, fewer states).
  4. Draw the state diagram. Circles are states, arrows are transitions, and labels are event / output.
  5. Build the state table. For every state and input combination, write the next state and the outputs.
  6. Choose an encoding. Binary uses the fewest flip-flops; one-hot is fast and FPGA-friendly; Gray reduces switching.
  7. Write three blocks. (1) state register: always @(posedge clk or posedge rst); (2) next-state logic: combinational always @(*); (3) output logic: combinational or registered.
  8. Define reset. Asynchronous or synchronous, active high or low. Reset must force a safe state.
  9. Add a handshake. start begins the operation, busy stays high while running, and done pulses when the result is valid.
  10. Handle illegal states. Add a default transition back to IDLE, or use a safe encoding.
Three-block template: state register + next-state logic + output logic. Keeping them separate makes the FSM readable and avoids latches.

FSM + datapath: the FSM is the brain and the datapath is the muscle. The FSM outputs control signals; the datapath returns status signals. Draw them as two blocks with a control/status bus between them. In the sorting modules, the FSM controls the index registers, memory write enables, and the done flag; the datapath contains the array memory, comparators, and index arithmetic.

FSM واحد کنترل یک سیستم ترتیبی است. مرحلهٔ فعلی را در یک ثبات حالت نگه می‌دارد و با منطق ترکیبی حالت بعدی و خروجی‌ها را تعیین می‌کند.

  1. حالت‌ها را با کلمه فهرست کن. مثلاً IDLE، SCAN، SWAP، DONE.
  2. رویدادها و گذارها را فهرست کن. کدام ورودی یا شرط، ماشین را از یک حالت به حالت دیگر می‌برد؟
  3. Moore یا Mealy را انتخاب کن. خروجی Moore فقط به حالت وابسته است (امن‌تر و ساده‌تر برای دیباگ). خروجی Mealy به حالت و ورودی وابسته است (سریع‌تر و با حالت‌های کمتر).
  4. نمودار حالت بکش. دایره‌ها حالت‌ها، فلش‌ها گذارها و برچسب‌ها به‌صورت رویداد / خروجی هستند.
  5. جدول حالت بساز. برای هر حالت و هر ترکیب ورودی، حالت بعدی و خروجی‌ها را بنویس.
  6. کدگذاری را انتخاب کن. باینری کمترین فلیپ‌فلاپ را می‌خواهد؛ one-hot سریع و مناسب FPGA است؛ Gray سوئیچینگ را کم می‌کند.
  7. سه بلوک بنویس. (۱) ثبات حالت: always @(posedge clk or posedge rst)؛ (۲) منطق حالت بعدی: always @(*)؛ (۳) منطق خروجی: ترکیبی یا ثبات‌دار.
  8. ریست را تعریف کن. غیرهمگام یا همگام، فعال بالا یا پایین. ریست باید ماشین را به یک حالت امن ببرد.
  9. Handshake اضافه کن. start عملیات را شروع می‌کند، busy در طول اجرا بالا می‌ماند و done وقتی نتیجه معتبر است یک پالس می‌دهد.
  10. حالت‌های غیرمجاز را مدیریت کن. یک گذار default به IDLE اضافه کن یا از کدگذاری امن استفاده کن.
الگوی سه‌بلوکی: ثبات حالت + منطق حالت بعدی + منطق خروجی. جدا نگه‌داشتن این سه، FSM را خوانا می‌کند و از latch شدن جلوگیری می‌کند.

FSM + دیتاپدیت: FSM مغز و دیتاپدیت عضله است. FSM سیگنال‌های کنترل را می‌دهد و دیتاپدیت سیگنال‌های وضعیت را برمی‌گرداند. آن‌ها را دو بلوک با یک باس کنترل/وضعیت بین‌شان بکش. در ماژول‌های مرتب‌سازی، FSM ثبات‌های اندیس، enable نوشتن حافظه و فلگ done را کنترل می‌کند؛ دیتاپدیت شامل حافظهٔ آرایه، مقایسه‌کننده‌ها و حساب اندیس است.

Conventionsقراردادها

Library conventionsقراردادهای کتابخانه

  • Verilog-2001/2005, synthesizable, no SystemVerilog-only constructs.
  • Widths, depths, moduli, and array sizes are parameters.
  • Clocked modules use clk; reset is asynchronous and active high unless noted. flip_flop uses active-low rst_n.
  • Array ports are flattened: element k is data_in[k*WIDTH +: WIDTH].
  • Array modules use a start / busy / done handshake; done is a one-cycle pulse.
  • Sorting, max/min, and binary search compare unsigned values.
  • Verilog-2001/2005، قابل سنتز، بدون ساختارهای مخصوص SystemVerilog.
  • عرض‌ها، عمق‌ها، پیمانه‌ها و اندازهٔ آرایه‌ها پارامتر هستند.
  • ماژول‌های کلاک‌دار از clk استفاده می‌کنند؛ ریست غیرهمگام و فعال بالا است مگر اینکه ذکر شود. flip_flop از rst_n فعال پایین استفاده می‌کند.
  • پورت‌های آرایه‌ای مسطح هستند: عنصر k برابر data_in[k*WIDTH +: WIDTH] است.
  • ماژول‌های آرایه‌ای از handshake start / busy / done استفاده می‌کنند؛ done یک پالس یک‌کلاکی است.
  • مرتب‌سازی، بیشینه/کمینه و جستجوی دودویی مقادیر بدون علامت را مقایسه می‌کنند.

Adderجمع‌کننده add

Combinational adder with carry-out and signed overflow.جمع‌کنندهٔ ترکیبی با رقم نقلی خروجی و سرریز علامت‌دار.

rtl/add.v

Explanationتوضیح

Adds two WIDTH-bit operands and a carry-in. The result is WIDTH bits wide; an extra internal bit captures cout. Signed overflow is detected when both operands have the same sign but the result has the opposite sign.

  • No clock: the output follows the inputs after the combinational delay.
  • Use it as the ALU adder in a datapath or as a building block for counters and address generators.
  • For subtraction, either use sub or feed the two's complement of b plus cin = 1.

دو عملوند WIDTH بیتی و یک رقم نقلی ورودی را جمع می‌کند. نتیجه WIDTH بیت است و یک بیت داخلی اضافی cout را نگه می‌دارد. سرریز علامت‌دار وقتی تشخیص داده می‌شود که دو عملوند هم‌علامت باشند ولی نتیجه علامت مخالف بگیرد.

  • کلاک ندارد: خروجی بعد از تأخیر ترکیبی از ورودی‌ها تبعیت می‌کند.
  • به‌عنوان جمع‌کنندهٔ ALU در دیتاپدیت یا بلوک سازندهٔ شمارنده و مولد آدرس استفاده می‌شود.
  • برای تفریق یا از sub استفاده کن یا مکمل دو b را با cin = 1 بده.

rtl/add.v
// ============================================================================
// Module: add  (Adder)
// ----------------------------------------------------------------------------
// Description:
//   Combinational (clockless) adder with configurable width.
//   Computes sum = a + b + cin and also produces carry-out and signed overflow.
//
// Parameters:
//   WIDTH : Bit width of the operands and result (default 8)
//
// Inputs:
//   a   : First operand  (WIDTH bits)
//   b   : Second operand (WIDTH bits)
//   cin : Carry-in
//
// Outputs:
//   sum      : Sum result (WIDTH bits)
//   cout     : Carry-out
//   overflow : Signed overflow; asserted when both operands have the same sign
//              but the result has a different sign.
// ============================================================================
module add #(
    parameter WIDTH = 8
)(
    input  wire [WIDTH-1:0] a,
    input  wire [WIDTH-1:0] b,
    input  wire             cin,
    output wire [WIDTH-1:0] sum,
    output wire             cout,
    output wire             overflow
);

    // One extra bit is used so the carry-out is not lost.
    wire [WIDTH:0] result;

    assign result = {1'b0, a} + {1'b0, b} + cin;

    assign sum  = result[WIDTH-1:0];
    assign cout = result[WIDTH];

    // Signed overflow: operands have equal signs but the result sign differs.
    assign overflow = (a[WIDTH-1] == b[WIDTH-1]) &&
                      (sum[WIDTH-1] != a[WIDTH-1]);

endmodule

// ============================================================================
// Testbench: tb_add
// Checks the combinational adder against the expected {cout, sum}.
// ============================================================================
`timescale 1ns/1ps

module tb_add;
    parameter WIDTH = 8;

    reg  [WIDTH-1:0] a;
    reg  [WIDTH-1:0] b;
    reg              cin;
    wire [WIDTH-1:0] sum;
    wire             cout;
    wire             overflow;

    integer errors;
    integer i;

    add #(.WIDTH(WIDTH)) dut (
        .a(a), .b(b), .cin(cin),
        .sum(sum), .cout(cout), .overflow(overflow)
    );

    task check;
        input [WIDTH-1:0] ta;
        input [WIDTH-1:0] tb;
        input             tc;
        reg   [WIDTH:0]   expected;
        begin
            a   = ta;
            b   = tb;
            cin = tc;
            #1;
            expected = {1'b0, ta} + {1'b0, tb} + tc;
            if ({cout, sum} !== expected) begin
                $display("FAIL add: a=%0d b=%0d cin=%b -> {cout,sum}={b}%0d expected={b}%0d",
                         ta, tb, tc, cout, sum, expected);
                errors = errors + 1;
            end
        end
    endtask

    initial begin
        errors = 0;

        check(8'd0,   8'd0,   1'b0);
        check(8'd1,   8'd1,   1'b0);
        check(8'd255, 8'd1,   1'b0);
        check(8'd128, 8'd127, 1'b0);
        check(8'd100, 8'd50,  1'b1);
        check(8'd255, 8'd255, 1'b1);
        check(8'd42,  8'd17,  1'b0);

        for (i = 0; i < 8; i = i + 1)
            check(i, 8'd255 - i, 1'b0);

        if (errors == 0)
            $display("tb_add: PASS");
        else
            $display("tb_add: FAIL (%0d errors)", errors);

        $finish;
    end
endmodule

Combinational subtractor with borrow-out and signed overflow.تفریق‌کنندهٔ ترکیبی با رقم قرض خروجی و سرریز علامت‌دار.

rtl/sub.v

Explanationتوضیح

Computes diff = a - b - bin. The extra internal bit captures bout. Signed overflow is detected when the operands have different signs and the result sign differs from a.

  • Pure combinational logic; no clock or state.
  • Useful for address differences, comparators built from subtractors, and ALU subtraction.

diff = a - b - bin را حساب می‌کند. بیت داخلی اضافی bout را نگه می‌دارد. سرریز علامت‌دار وقتی تشخیص داده می‌شود که دو عملوند علامت متفاوت داشته باشند و علامت نتیجه با a فرق کند.

  • منطق کاملاً ترکیبی؛ بدون کلاک و حالت.
  • برای اختلاف آدرس، مقایسه‌کننده‌های ساخته‌شده از تفریق‌کننده و تفریق ALU مناسب است.

// ============================================================================
// Module: add_sub  (Adder/Subtractor with flag)
// ----------------------------------------------------------------------------
// Description:
//   As you suggested, building separate add and subtract blocks is a bit
//   pointless; this module performs both using a single flag (sub_flag).
//     sub_flag = 0  =>  result = a + b + cin
//     sub_flag = 1  =>  result = a - b - cin
//
// Parameters:
//   WIDTH : Bit width of the operands and result (default 8)
//
// Inputs:
//   a        : First operand (WIDTH bits)
//   b        : Second operand (WIDTH bits)
//   sub_flag : Operation select; 0 = add, 1 = subtract
//   cin      : Carry-in / borrow-in
//
// Outputs:
//   result   : Add or subtract result (WIDTH bits)
//   cout     : Carry-out / borrow-out
//   overflow : Signed overflow (depends on the operation)
// ============================================================================
module add_sub #(
    parameter WIDTH = 8
)(
    input  wire [WIDTH-1:0] a,
    input  wire [WIDTH-1:0] b,
    input  wire             sub_flag,
    input  wire             cin,
    output reg  [WIDTH-1:0] result,
    output reg              cout,
    output reg              overflow
);

    always @(*) begin
        if (!sub_flag) begin
            // Addition
            {cout, result} = {1'b0, a} + {1'b0, b} + cin;
            overflow = (a[WIDTH-1] == b[WIDTH-1]) &&
                       (result[WIDTH-1] != a[WIDTH-1]);
        end else begin
            // Subtraction
            {cout, result} = {1'b0, a} - {1'b0, b} - cin;
            overflow = (a[WIDTH-1] != b[WIDTH-1]) &&
                       (result[WIDTH-1] != a[WIDTH-1]);
        end
    end

endmodule

// ============================================================================
// Module: mul  (Multiplier)
// ----------------------------------------------------------------------------
// Description:
//   Multiplies two numbers. The result width equals the sum of the two operand
//   widths so no product bits are lost. Both unsigned and signed (two's
//   complement) operation are supported through the SIGNED parameter.
//
// Parameters:
//   A_WIDTH : Width of operand a (default 8)
//   B_WIDTH : Width of operand b (default 8)
//   P_WIDTH : Width of the product (default A_WIDTH + B_WIDTH)
//   SIGNED  : 0 = unsigned, 1 = signed (default 0)
//
// Inputs:
//   a : First operand  (A_WIDTH bits)
//   b : Second operand (B_WIDTH bits)
//
// Outputs:
//   p : Product (P_WIDTH bits)
// ============================================================================
module mul #(
    parameter A_WIDTH = 8,
    parameter B_WIDTH = 8,
    parameter P_WIDTH = A_WIDTH + B_WIDTH,
    parameter SIGNED  = 0
)(
    input  wire [A_WIDTH-1:0] a,
    input  wire [B_WIDTH-1:0] b,
    output wire [P_WIDTH-1:0] p
);

    generate
        if (SIGNED) begin : g_signed
            // Signed (two's complement) multiplication
            assign p = $signed(a) * $signed(b);
        end else begin : g_unsigned
            // Unsigned multiplication
            assign p = a * b;
        end
    endgenerate

endmodule

// ============================================================================
// Module: mux  (Multiplexer)
// ----------------------------------------------------------------------------
// Description:
//   Parameterized multiplexer. It has N inputs, each WIDTH bits wide, and
//   connects one of them to the output based on sel. The inputs are packed
//   into a single vector (input 0 in the lowest bits, input N-1 in the highest).
//
// Parameters:
//   WIDTH     : Width of each input/output (default 8)
//   N         : Number of inputs (default 4)
//   SEL_WIDTH : Select width; automatically ceil(log2(N))
//
// Inputs:
//   in  : Packed input vector, N*WIDTH bits
//   sel : Index of the selected input, SEL_WIDTH bits
//
// Outputs:
//   out : Selected input, WIDTH bits
// ============================================================================
module mux #(
    parameter WIDTH     = 8,
    parameter N         = 4,
    parameter SEL_WIDTH = (N <= 2) ? 1 : $clog2(N)
)(
    input  wire [N*WIDTH-1:0]   in,
    input  wire [SEL_WIDTH-1:0] sel,
    output reg  [WIDTH-1:0]     out
);

    integer i;

    always @(*) begin
        // Default to zero so the output is never floating for an invalid sel.
        out = {WIDTH{1'b0}};
        for (i = 0; i < N; i = i + 1) begin
            if (sel == i)
                out = in[i*WIDTH +: WIDTH];
        end
    end

endmodule

// ============================================================================
// Module: parity  (Parity generator / checker)
// ----------------------------------------------------------------------------
// Description:
//   This module can both generate and check a parity bit.
//   - Generate mode (check_mode = 0): produces the parity bit for data.
//   - Check mode (check_mode = 1): compares the received parity bit
//     (parity_in) with the computed one and asserts error on a mismatch.
//
// Parameters:
//   WIDTH : Data width (default 8)
//   EVEN  : 1 = even parity, 0 = odd parity (default 1)
//
// Inputs:
//   data       : Input data (WIDTH bits)
//   parity_in  : Received parity bit (used in check mode)
//   check_mode : 0 = generate, 1 = check
//
// Outputs:
//   parity_out : Generated parity bit
//   error      : Parity error; only meaningful in check mode
// ============================================================================
module parity #(
    parameter WIDTH = 8,
    parameter EVEN  = 1
)(
    input  wire [WIDTH-1:0] data,
    input  wire             parity_in,
    input  wire             check_mode,
    output wire             parity_out,
    output wire             error
);

    // XOR of all bits: for even parity this is 1 when the number of ones is odd.
    wire xor_all;

    assign xor_all    = ^data;
    assign parity_out = EVEN ? xor_all : ~xor_all;
    assign error      = check_mode ? (parity_in != parity_out) : 1'b0;

endmodule

// ============================================================================
// Module: flip_flop  (D flip-flop)
// ----------------------------------------------------------------------------
// Description:
//   A parameterized-width D flip-flop. On the rising clock edge, if enable is
//   asserted, d is stored into q. The reset is asynchronous and active low
//   (rst_n). A complemented output is also provided.
//
// Parameters:
//   WIDTH       : Data/output width (default 1)
//   RESET_VALUE : Value loaded into q during reset (default 0)
//
// Inputs:
//   clk   : Clock
//   rst_n : Asynchronous reset, active low
//   en    : Storage enable
//   d     : Input data (WIDTH bits)
//
// Outputs:
//   q     : Output (WIDTH bits)
//   q_bar : Complemented output (WIDTH bits)
// ============================================================================
module flip_flop #(
    parameter WIDTH       = 1,
    parameter RESET_VALUE = 0
)(
    input  wire             clk,
    input  wire             rst_n,
    input  wire             en,
    input  wire [WIDTH-1:0] d,
    output reg  [WIDTH-1:0] q,
    output wire [WIDTH-1:0] q_bar
);

    assign q_bar = ~q;

    always @(posedge clk or negedge rst_n) begin
        if (!rst_n)
            q <= RESET_VALUE;
        else if (en)
            q <= d;
    end

// ============================================================================
// Module: shift_register  (Shift register)
// ----------------------------------------------------------------------------
// Description:
//   A shift register with the requested controls:
//     init     : loads INIT_VALUE into the register (initialization)
//     load_reg : parallel load from parallel_in
//     shift_en : enables shifting (one bit per clock)
//   Priority: rst > init > load_reg > shift_en
//   The shift direction is selected by the DIR parameter.
//
// Parameters:
//   WIDTH      : Register width (default 8)
//   DIR        : 0 = shift right, 1 = shift left (default 0)
//   INIT_VALUE : Value loaded by init (default 0)
//
// Inputs:
//   clk         : Clock
//   rst         : Asynchronous reset, active high
//   shift_en    : Shift enable
//   init        : Initialize the register
//   load_reg    : Parallel load enable
//   serial_in   : Bit shifted into the register on each shift
//   parallel_in : Parallel load data (WIDTH bits)
//
// Outputs:
//   q          : Register value (WIDTH bits)
//   serial_out : Bit shifted out from the opposite side
// ============================================================================
module shift_register #(
    parameter WIDTH      = 8,
    parameter DIR        = 0,
    parameter INIT_VALUE = 0
)(
    input  wire             clk,
    input  wire             rst,
    input  wire             shift_en,
    input  wire             init,
    input  wire             load_reg,
    input  wire             serial_in,
    input  wire [WIDTH-1:0] parallel_in,
    output reg  [WIDTH-1:0] q,
    output wire             serial_out
);

    // Serial output comes from the side the register shifts towards.
    assign serial_out = (DIR == 0) ? q[0] : q[WIDTH-1];

    always @(posedge clk or posedge rst) begin
        if (rst) begin
            q <= INIT_VALUE;
        end else if (init) begin
            q <= INIT_VALUE;
        end else if (load_reg) begin
            q <= parallel_in;
        end else if (shift_en) begin
            if (DIR == 0)
                q <= {serial_in, q[WIDTH-1:1]};   // Shift right
            else
                q <= {q[WIDTH-2:0], serial_in};   // Shift left
        end
    end

endmodule

        shift_en  = 1'b1;
        serial_in = 1'b1;
        @(posedge clk); #1;

        if (q_right !== 8'hD2) begin
            $display("FAIL shift_register right shift: q_right=%h expected=D2", q_right);
            errors = errors + 1;
        end
        if (q_left !== 8'h4B) begin
            $display("FAIL shift_register left shift: q_left=%h expected=4B", q_left);
            errors = errors + 1;
        end

        // Second shift with serial_in = 0
        serial_in = 1'b0;
        @(posedge clk); #1;
        if (q_right !== 8'h69) begin
            $display("FAIL shift_register right shift 2: q_right=%h expected=69", q_right);
            errors = errors + 1;
        end
        if (q_left !== 8'h96) begin
            $display("FAIL shift_register left shift 2: q_left=%h expected=96", q_left);
            errors = errors + 1;
        end
        shift_en = 1'b0;

        // Init has priority over load/shift
        init        = 1'b1;
        load_reg    = 1'b1;
        shift_en    = 1'b1;
        parallel_in = 8'hFF;
        @(posedge clk); #1;
        if (q_right !== INIT_VALUE || q_left !== INIT_VALUE) begin
            $display("FAIL shift_register init: q_right=%h q_left=%h expected=%h",
                     q_right, q_left, INIT_VALUE);
            errors = errors + 1;
        end

        if (errors == 0)
            $display("tb_shift_register: PASS");
        else
            $display("tb_shift_register: FAIL (%0d errors)", errors);

        $finish;
    end

// ============================================================================
// Module: universal_shift  (Universal shift register)
// ----------------------------------------------------------------------------
// Description:
//   A universal shift register that performs four operations selected by mode:
//     mode = 00 : hold
//     mode = 01 : shift right
//     mode = 10 : shift left
//     mode = 11 : parallel load
//   Note: Verilog's >> and << operators also perform shifts, but this module
//   is the synthesizable hardware version with full control.
//
// Parameters:
//   WIDTH : Register width (default 8)
//
// Inputs:
//   clk          : Clock
//   rst          : Asynchronous reset, active high
//   mode         : Operation select (2 bits)
//   serial_right : Bit shifted in at the MSB side during a right shift
//   serial_left  : Bit shifted in at the LSB side during a left shift
//   parallel_in  : Parallel load value (WIDTH bits)
//
// Outputs:
//   q                : Register value (WIDTH bits)
//   serial_out_right : Bit shifted out at the LSB side during a right shift
//   serial_out_left  : Bit shifted out at the MSB side during a left shift
// ============================================================================
module universal_shift #(
    parameter WIDTH = 8
)(
    input  wire             clk,
    input  wire             rst,
    input  wire [1:0]       mode,
    input  wire             serial_right,
    input  wire             serial_left,
    input  wire [WIDTH-1:0] parallel_in,
    output reg  [WIDTH-1:0] q,
    output wire             serial_out_right,
    output wire             serial_out_left
);

    assign serial_out_right = q[0];
    assign serial_out_left  = q[WIDTH-1];

    always @(posedge clk or posedge rst) begin
        if (rst) begin
            q <= {WIDTH{1'b0}};
        end else begin
            case (mode)
                2'b00: q <= q;                              // Hold
                2'b01: q <= {serial_right, q[WIDTH-1:1]};   // Shift right
                2'b10: q <= {q[WIDTH-2:0], serial_left};    // Shift left
                2'b11: q <= parallel_in;                    // Parallel load
            endcase
        end
    end

endmodule

// ============================================================================
// Module: up_down_counter  (Up/down counter)
// ----------------------------------------------------------------------------
// Description:
//   An up/down counter with a configurable range.
//   - count_up = 1 : counts up
//   - count_up = 0 : counts down
//   - count_en = 1 : counting is enabled
//   - serial_in    : Carry-in / serial enable used to chain counters
//                    (tie it to 1 for standalone operation)
//   - done         : Last state reached (MAX_VALUE when counting up,
//                    MIN_VALUE when counting down)
//   The counter wraps around at the boundaries.
//
// Parameters:
//   WIDTH     : Counter width (default 8)
//   MIN_VALUE : Minimum value (default 0)
//   MAX_VALUE : Maximum value (default 2^WIDTH - 1)
//
// Inputs:
//   clk       : Clock
//   rst       : Asynchronous reset, active high (loads MIN_VALUE)
//   count_en  : Count enable
//   count_up  : Count direction; 1 = up, 0 = down
//   serial_in : Carry-in / serial enable
//
// Outputs:
//   value : Current counter value
//   done  : Counting boundary reached
// ============================================================================
module up_down_counter #(
    parameter WIDTH     = 8,
    parameter MIN_VALUE = 0,
    parameter MAX_VALUE = (1 << WIDTH) - 1
)(
    input  wire             clk,
    input  wire             rst,
    input  wire             count_en,
    input  wire             count_up,
    input  wire             serial_in,
    output reg  [WIDTH-1:0] value,
    output wire             done
);

    // done reflects reaching the ceiling or floor depending on direction.
    assign done = count_up ? (value == MAX_VALUE) : (value == MIN_VALUE);

    always @(posedge clk or posedge rst) begin
        if (rst) begin
            value <= MIN_VALUE;
        end else if (count_en && serial_in) begin
            if (count_up) begin
                if (value >= MAX_VALUE)
                    value <= MIN_VALUE;   // Wrap at the ceiling
                else
                    value <= value + 1'b1;
            end else begin
                if (value <= MIN_VALUE)
                    value <= MAX_VALUE;   // Wrap at the floor
                else
                    value <= value - 1'b1;
            end
        end
    end

endmodule

// Module: residue_n  (Modulo-N counter / residue)
// ----------------------------------------------------------------------------
// Description:
//   A modulo-N counter that counts from 0 to N-1 and wraps back to zero after
//   N-1; therefore the output is always the residue modulo N. done is asserted
//   while the counter is at N-1.
//
// Parameters:
//   N     : Counter modulus (default 10)
//   WIDTH : Output width; automatically ceil(log2(N))
//
// Inputs:
//   clk : Clock
//   rst : Asynchronous reset, active high
//   en  : Count enable
//
// Outputs:
//   value : Current counter value (0 to N-1)
//   done  : Asserted when value == N-1 (last state reached)
// ============================================================================
module residue_n #(
    parameter N     = 10,
    parameter WIDTH = (N <= 2) ? 1 : $clog2(N)
)(
    input  wire             clk,
    input  wire             rst,
    input  wire             en,
    output reg  [WIDTH-1:0] value,
    output wire             done
);

    assign done = (value == N - 1);

    always @(posedge clk or posedge rst) begin
        if (rst) begin
            value <= {WIDTH{1'b0}};
        end else if (en) begin
            if (value == N - 1)
                value <= {WIDTH{1'b0}};   // Wrap back to zero (modulo N)
            else
                value <= value + 1'b1;
        end
    end

            errors = errors + 1;
        end

            $display("tb_residue_n: PASS");
        else
            $display("tb_residue_n: FAIL (%0d errors)", errors);

        $finish;
    end

// ============================================================================
// Module: register_file  (Register file)
// ----------------------------------------------------------------------------
// Description:
//   An array of DEPTH registers, each WIDTH bits wide. It has one write port
//   and two read ports (asynchronous/combinational read). rst clears all
//   registers to zero.
//
// Parameters:
//   WIDTH      : Width of each register (default 32)
//   DEPTH      : Number of registers (default 32)
//   ADDR_WIDTH : Address width; automatically ceil(log2(DEPTH))
//
// Inputs:
//   clk    : Clock
//   rst    : Asynchronous reset, active high (clears all registers)
//   we     : Write enable
//   waddr  : Write address
//   wdata  : Write data
//   raddr1 : Read address, port 1
//   raddr2 : Read address, port 2
//
// Outputs:
//   rdata1 : Read data, port 1
//   rdata2 : Read data, port 2
// ============================================================================
module register_file #(
    parameter WIDTH      = 32,
    parameter DEPTH      = 32,
    parameter ADDR_WIDTH = $clog2(DEPTH)
)(
    input  wire                  clk,
    input  wire                  rst,
    input  wire                  we,
    input  wire [ADDR_WIDTH-1:0] waddr,
    input  wire [WIDTH-1:0]      wdata,
    input  wire [ADDR_WIDTH-1:0] raddr1,
    input  wire [ADDR_WIDTH-1:0] raddr2,
    output wire [WIDTH-1:0]      rdata1,
    output wire [WIDTH-1:0]      rdata2
);

    // Register array
    reg [WIDTH-1:0] mem [0:DEPTH-1];

    integer i;

    always @(posedge clk or posedge rst) begin
        if (rst) begin
            for (i = 0; i < DEPTH; i = i + 1)
                mem[i] <= {WIDTH{1'b0}};
        end else if (we) begin
            mem[waddr] <= wdata;
        end
    end

    // Combinational (asynchronous) read
    assign rdata1 = mem[raddr1];
    assign rdata2 = mem[raddr2];

endmodule

Selection Sortمرتب‌سازی انتخابی selection_sort

In-place selection sort, one comparison per clock.مرتب‌سازی انتخابی درجا، یک مقایسه در هر کلاک.

rtl/selection_sort.v

Explanationتوضیح

For each position i, the FSM scans the unsorted suffix i..N-1, remembers the index of the minimum, and swaps it into position i. The array is copied into internal memory when start is asserted.

  • One comparison per clock; the total work is N(N-1)/2 comparisons.
  • data_out is continuously driven from internal memory; sample it while done is high.
  • Comparisons are unsigned.

  • data_out به‌طور پیوسته از حافظهٔ داخلی تغذیه می‌شود؛ وقتی done بالاست آن را بخوان.
  • مقایسه‌ها بدون علامت هستند.

rtl/selection_sort.v
// ============================================================================
// Module: selection_sort  (Selection sort)
// ----------------------------------------------------------------------------
// Description:
//   Sorts an array of N unsigned elements in ascending order using the
//   selection-sort algorithm. The array is sampled from data_in when start is
//   asserted; the module then sorts it over multiple clock cycles.
//   For each position i, it scans the remaining elements to find the minimum
//   and swaps it into position i. One comparison is performed per clock cycle.
//
//   Handshake:
//     - Pulse start for at least one clock while busy is low.
//     - busy goes high during sorting and low again when finished.
//     - done is a one-cycle pulse when data_out holds the sorted array.
//
// Parameters:
//   N     : Number of elements in the array (default 8)
//   WIDTH : Bit width of each element (default 8)
//
// Inputs:
//   clk      : Clock
//   rst      : Asynchronous reset, active high
//   start    : Start sorting (pulse)
//   data_in  : Flattened input array, N*WIDTH bits
//              (element k = data_in[k*WIDTH +: WIDTH])
//
// Outputs:
//   data_out : Flattened sorted array, N*WIDTH bits
//   done     : One-cycle completion pulse
//   busy     : High while sorting
// ============================================================================
module selection_sort #(
    parameter N     = 8,
    parameter WIDTH = 8
)(
    input  wire               clk,
    input  wire               rst,
    input  wire               start,
    input  wire [N*WIDTH-1:0] data_in,
    output wire [N*WIDTH-1:0] data_out,
    output reg                done,
    output reg                busy
);

    localparam IDLE = 2'd0;
    localparam SCAN = 2'd1;
    localparam SWAP = 2'd2;
    localparam FIN  = 2'd3;

    reg [WIDTH-1:0] mem [0:N-1];
    reg [1:0]       state;

    integer i, j, min_idx, k;

    // Expose the internal array as a flat output vector.
    genvar g;
    generate
        for (g = 0; g < N; g = g + 1) begin : g_out
            assign data_out[g*WIDTH +: WIDTH] = mem[g];
        end
    endgenerate

    always @(posedge clk or posedge rst) begin
        if (rst) begin
            state   <= IDLE;
            done    <= 1'b0;
            busy    <= 1'b0;
            i       <= 0;
            j       <= 0;
            min_idx <= 0;
        end else begin
            case (state)
                IDLE: begin
                    done <= 1'b0;
                    busy <= 1'b0;
                    if (start) begin
                        // Load the input array into internal memory.
                        for (k = 0; k < N; k = k + 1)
                            mem[k] <= data_in[k*WIDTH +: WIDTH];

                        i <= 0;
                        if (N <= 1) begin
                            state <= FIN;
                        end else begin
                            min_idx <= 0;
                            j       <= 1;
                            busy    <= 1'b1;
                            state   <= SCAN;
                        end
                    end
                end

                // Scan the unsorted part for the minimum element.
                SCAN: begin
                    if (mem[j] < mem[min_idx])
                        min_idx <= j;

                    if (j == N-1)
                        state <= SWAP;
                    else
                        j <= j + 1;
                end

                // Swap the minimum into position i and advance.
                SWAP: begin
                    mem[i]       <= mem[min_idx];
                    mem[min_idx] <= mem[i];

                    if (i == N-2) begin
                        state <= FIN;
                    end else begin
                        i       <= i + 1;
                        min_idx <= i + 1;
                        j       <= i + 2;
                        state   <= SCAN;
                    end
                end

                FIN: begin
                    busy  <= 1'b0;
                    done  <= 1'b1;
                    state <= IDLE;
                end

                default: state <= IDLE;
            endcase
        end
    end

endmodule

In-place insertion sort, one shift per clock.مرتب‌سازی درجی درجا، یک شیفت در هر کلاک.

rtl/insertion_sort.v

Explanationتوضیح

For i = 1 .. N-1, the FSM captures key = mem[i] and shifts larger elements of the sorted prefix one position to the right. It then writes the key into the gap. One shift happens per clock.

  • Best case (already sorted) is O(N); worst case is O(N^2).
  • Stable and in-place; good for small arrays or nearly sorted data.

  • بهترین حالت (آرایهٔ از قبل مرتب) O(N) و بدترین حالت O(N^2) است.
  • پایدار و درجاست؛ برای آرایه‌های کوچک یا تقریباً مرتب مناسب است.

// ============================================================================
// Module: insertion_sort  (Insertion sort)
// ----------------------------------------------------------------------------
// Description:
//   Sorts an array of N unsigned elements in ascending order using the
//   insertion-sort algorithm. The array is sampled from data_in when start is
//   asserted. For i = 1 .. N-1, the key mem[i] is inserted into the already
//   sorted prefix by shifting larger elements one position to the right.
//   One shift is performed per clock cycle.
//
//   Handshake:
//     - Pulse start for at least one clock while busy is low.
//     - busy goes high during sorting and low again when finished.
//     - done is a one-cycle pulse when data_out holds the sorted array.
//
// Parameters:
//   N     : Number of elements in the array (default 8)
//   WIDTH : Bit width of each element (default 8)
//
// Inputs:
//   clk      : Clock
//   rst      : Asynchronous reset, active high
//   start    : Start sorting (pulse)
//   data_in  : Flattened input array, N*WIDTH bits
//              (element k = data_in[k*WIDTH +: WIDTH])
//
// Outputs:
//   data_out : Flattened sorted array, N*WIDTH bits
//   done     : One-cycle completion pulse
//   busy     : High while sorting
// ============================================================================
module insertion_sort #(
    parameter N     = 8,
    parameter WIDTH = 8
)(
    input  wire               clk,
    input  wire               rst,
    input  wire               start,
    input  wire [N*WIDTH-1:0] data_in,
    output wire [N*WIDTH-1:0] data_out,
    output reg                done,
    output reg                busy
);

    localparam IDLE  = 3'd0;
    localparam PICK  = 3'd1;
    localparam SHIFT = 3'd2;
    localparam PLACE = 3'd3;
    localparam NEXT  = 3'd4;
    localparam FIN   = 3'd5;

    reg [WIDTH-1:0] mem [0:N-1];
    reg [WIDTH-1:0] key;
    reg [2:0]       state;

    integer i, j, k;

    // Expose the internal array as a flat output vector.
    genvar g;
    generate
        for (g = 0; g < N; g = g + 1) begin : g_out
            assign data_out[g*WIDTH +: WIDTH] = mem[g];
        end
    endgenerate

    always @(posedge clk or posedge rst) begin
        if (rst) begin
            state <= IDLE;
            done  <= 1'b0;
            busy  <= 1'b0;
            i     <= 0;
            j     <= 0;
        end else begin
            case (state)
                IDLE: begin
                    done <= 1'b0;
                    busy <= 1'b0;
                    if (start) begin
                        // Load the input array into internal memory.
                        for (k = 0; k < N; k = k + 1)
                            mem[k] <= data_in[k*WIDTH +: WIDTH];

                        i <= 1;
                        if (N <= 1) begin
                            state <= FIN;
                        end else begin
                            busy  <= 1'b1;
                            state <= PICK;
                        end
                    end
                end

                // Capture the element to insert and start scanning left.
                PICK: begin
                    key   <= mem[i];
                    j     <= i - 1;
                    state <= SHIFT;
                end

                // Shift larger elements one position to the right.
                SHIFT: begin
                    if (j >= 0) begin
                        if (mem[j] > key) begin
                            mem[j+1] <= mem[j];
                            j        <= j - 1;
                        end else begin
                            state <= PLACE;
                        end
                    end else begin
                        state <= PLACE;
                    end
                end

                // Store the key in its final position.
                PLACE: begin
                    mem[j+1] <= key;
                    state    <= NEXT;
                end

                // Move to the next element or finish.
                NEXT: begin
                    if (i == N-1) begin
                        state <= FIN;
                    end else begin
                        i     <= i + 1;
                        state <= PICK;
                    end
                end

                FIN: begin
                    busy  <= 1'b0;
                    done  <= 1'b1;
                    state <= IDLE;
                end

                default: state <= IDLE;
            endcase
        end
    end

// ----------------------------------------------------------------------------
// Description:
//   Sorts an array of N unsigned elements in ascending order using the
//   bubble-sort algorithm. The array is sampled from data_in when start is
//   asserted. Repeated passes compare adjacent elements and swap them when
//   they are out of order; after pass i the largest i+1 elements are in place.
//   One comparison is performed per clock cycle.
//
//   Handshake:
//     - Pulse start for at least one clock while busy is low.
//     - busy goes high during sorting and low again when finished.
//     - done is a one-cycle pulse when data_out holds the sorted array.
//
// Parameters:
//   N     : Number of elements in the array (default 8)
//   WIDTH : Bit width of each element (default 8)
//
// Inputs:
//   clk      : Clock
//   rst      : Asynchronous reset, active high
//   start    : Start sorting (pulse)
//   data_in  : Flattened input array, N*WIDTH bits
//              (element k = data_in[k*WIDTH +: WIDTH])
//
// Outputs:
//   data_out : Flattened sorted array, N*WIDTH bits
//   done     : One-cycle completion pulse
//   busy     : High while sorting
// ============================================================================
module bubble_sort #(
    parameter N     = 8,
    parameter WIDTH = 8
)(
    input  wire               clk,
    input  wire               rst,
    input  wire               start,
    input  wire [N*WIDTH-1:0] data_in,
    output wire [N*WIDTH-1:0] data_out,
    output reg                done,
    output reg                busy
);

    localparam IDLE = 2'd0;
    localparam CMP  = 2'd1;
    localparam FIN  = 2'd2;

    reg [WIDTH-1:0] mem [0:N-1];
    reg [1:0]       state;

    integer i, j, k;

    // Expose the internal array as a flat output vector.
    genvar g;
    generate
        for (g = 0; g < N; g = g + 1) begin : g_out
            assign data_out[g*WIDTH +: WIDTH] = mem[g];
        end
    endgenerate

    always @(posedge clk or posedge rst) begin
        if (rst) begin
            state <= IDLE;
            done  <= 1'b0;
            busy  <= 1'b0;
            i     <= 0;
            j     <= 0;
        end else begin
            case (state)
                IDLE: begin
                    done <= 1'b0;
                    busy <= 1'b0;
                    if (start) begin
                        // Load the input array into internal memory.
                        for (k = 0; k < N; k = k + 1)
                            mem[k] <= data_in[k*WIDTH +: WIDTH];

                        i <= 0;
                        j <= 0;
                        if (N <= 1) begin
                            state <= FIN;
                        end else begin
                            busy  <= 1'b1;
                            state <= CMP;
                        end
                    end
                end

                // Compare and swap one adjacent pair per cycle.
                CMP: begin
                    if (mem[j] > mem[j+1]) begin
                        mem[j]   <= mem[j+1];
                        mem[j+1] <= mem[j];
                    end

                    if (j == N-2-i) begin
                        j <= 0;
                        if (i == N-2) begin
                            state <= FIN;
                        end else begin
                            i     <= i + 1;
                            state <= CMP;
                        end
                    end else begin
                        j <= j + 1;
                    end
                end

                FIN: begin
                    busy  <= 1'b0;
                    done  <= 1'b1;
                    state <= IDLE;
                end

                default: state <= IDLE;
            endcase
        end
    end

                        // Load the input array into internal memory.
                        for (k = 0; k < N; k = k + 1)
                            mem[k] <= data_in[k*WIDTH +: WIDTH];

                        sp <= 0;
                        if (N <= 1) begin
                            state <= FIN;
                        end else begin
                            // Push the full range [0, N-1].
                            stack_low[0]  <= 0;
                            stack_high[0] <= N-1;
                            sp    <= 1;
                            busy  <= 1'b1;
                            state <= POP;
                        end
                    end
                end

                // Pop the next subrange to process.
                POP: begin
                    if (sp == 0) begin
                        state <= FIN;
                    end else begin
                        low   <= stack_low[sp-1];
                        high  <= stack_high[sp-1];
                        sp    <= sp - 1;
                        state <= SETUP;
                    end
                end

                // Skip empty/singleton subranges.
                SETUP: begin
                    if (low < high) begin
                        pivot <= mem[high];
                        i     <= low;
                        j     <= low;
                        state <= PART;
                    end else begin
                        state <= POP;
                    end
                end

                // Lomuto partition: elements < pivot move to the left.
                PART: begin
                    if (j < high) begin
                        if (mem[j] < pivot) begin
                            mem[i] <= mem[j];
                            mem[j] <= mem[i];
                            i      <= i + 1;
                        end
                        j <= j + 1;
                    end else begin
                        state <= PIVOT;
                    end
                end

                // Put the pivot in its final position and push subranges.
                PIVOT: begin
                    mem[i]    <= mem[high];
                    mem[high] <= mem[i];

                    if (i > low) begin
                        // Left subrange [low, i-1] is non-empty.
                        stack_low[sp]  <= low;
                        stack_high[sp] <= i - 1;

                        if (i < high) begin
                            // Right subrange [i+1, high] is also non-empty.
                            stack_low[sp+1]  <= i + 1;
                            stack_high[sp+1] <= high;
                            sp <= sp + 2;
                        end else begin
                            sp <= sp + 1;
                        end
                    end else if (i < high) begin
                        // Only the right subrange [i+1, high] is non-empty.
                        stack_low[sp]  <= i + 1;
                        stack_high[sp] <= high;
                        sp <= sp + 1;
                    end

                    state <= POP;
                end

                FIN: begin
                    busy  <= 1'b0;
                    done  <= 1'b1;
                    state <= IDLE;
                end

                default: state <= IDLE;
            endcase
        end
    end

// ============================================================================
// Module: array_max_min  (Array maximum/minimum finder)
// ----------------------------------------------------------------------------
// Description:
//   Finds the maximum and minimum elements of an array of N unsigned values.
//   The input array is scanned directly from data_in, one element per clock
//   cycle. The first element initializes both max_val and min_val.
//
//   Handshake:
//     - Pulse start for at least one clock while busy is low.
//     - busy goes high during the scan and low again when finished.
//     - done is a one-cycle pulse when max_val and min_val are valid.
//
// Parameters:
//   N     : Number of elements in the array (default 8)
//   WIDTH : Bit width of each element (default 8)
//
// Inputs:
//   clk      : Clock
//   rst      : Asynchronous reset, active high
//   start    : Start searching (pulse)
//   data_in  : Flattened input array, N*WIDTH bits
//              (element k = data_in[k*WIDTH +: WIDTH])
//
// Outputs:
//   max_val : Largest element found
//   min_val : Smallest element found
//   done    : One-cycle completion pulse
//   busy    : High while scanning
// ============================================================================
module array_max_min #(
    parameter N     = 8,
    parameter WIDTH = 8
)(
    input  wire               clk,
    input  wire               rst,
    input  wire               start,
    input  wire [N*WIDTH-1:0] data_in,
    output reg  [WIDTH-1:0]   max_val,
    output reg  [WIDTH-1:0]   min_val,
    output reg                done,
    output reg                busy
);

    localparam IDLE = 2'd0;
    localparam SCAN = 2'd1;
    localparam FIN  = 2'd2;

    reg [1:0] state;
    integer k;

    always @(posedge clk or posedge rst) begin
        if (rst) begin
            state   <= IDLE;
            done    <= 1'b0;
            busy    <= 1'b0;
            max_val <= {WIDTH{1'b0}};
            min_val <= {WIDTH{1'b0}};
            k       <= 0;
        end else begin
            case (state)
                IDLE: begin
                    done <= 1'b0;
                    busy <= 1'b0;
                    if (start) begin
                        // Initialize both with the first element.
                        max_val <= data_in[0 +: WIDTH];
                        min_val <= data_in[0 +: WIDTH];
                        k       <= 1;
                        if (N <= 1) begin
                            state <= FIN;
                        end else begin
                            busy  <= 1'b1;
                            state <= SCAN;
                        end
                    end
                end

                // Compare one element per cycle.
                SCAN: begin
                    if (k < N) begin
                        if (data_in[k*WIDTH +: WIDTH] > max_val)
                            max_val <= data_in[k*WIDTH +: WIDTH];

                        if (data_in[k*WIDTH +: WIDTH] < min_val)
                            min_val <= data_in[k*WIDTH +: WIDTH];

                        k <= k + 1;
                    end else begin
                        state <= FIN;
                    end
                end

                FIN: begin
                    busy  <= 1'b0;
                    done  <= 1'b1;
                    state <= IDLE;
                end

                default: state <= IDLE;
            endcase
        end
    end

endmodule

// ============================================================================
// Module: binary_search  (Binary search)
// ----------------------------------------------------------------------------
// Description:
//   Searches for key in a sorted array of N unsigned elements using binary
//   search. The array is read directly from data_in and one comparison is
//   performed per clock cycle. When a match is found, found is asserted and
//   index holds the matching position. If the key is not present, found stays
//   low and index is zero.
//
//   Handshake:
//     - Pulse start for at least one clock while busy is low.
//     - busy goes high during the search and low again when finished.
//     - done is a one-cycle pulse when found and index are valid.
//
// Parameters:
//   N     : Number of elements in the array (default 8)
//   WIDTH : Bit width of each element and of the key (default 8)
//   IDX_W : Index width; automatically ceil(log2(N))
//
// Inputs:
//   clk      : Clock
//   rst      : Asynchronous reset, active high
//   start    : Start searching (pulse)
//   data_in  : Flattened sorted array, N*WIDTH bits
//              (element k = data_in[k*WIDTH +: WIDTH])
//   key      : Value to search for (WIDTH bits)
//
// Outputs:
//   found : Asserted when key is present
//   index : Position of key when found (IDX_W bits)
//   done  : One-cycle completion pulse
//   busy  : High while searching
// ============================================================================
module binary_search #(
    parameter N     = 8,
    parameter WIDTH = 8,
    parameter IDX_W = (N <= 2) ? 1 : $clog2(N)
)(
    input  wire               clk,
    input  wire               rst,
    input  wire               start,
    input  wire [N*WIDTH-1:0] data_in,
    input  wire [WIDTH-1:0]   key,
    output reg                found,
    output reg  [IDX_W-1:0]   index,
    output reg                done,
    output reg                busy
);

    localparam IDLE   = 2'd0;
    localparam SEARCH = 2'd1;
    localparam FIN    = 2'd2;

    reg [1:0] state;

    // Signed integers are used so hi can become -1 without wrapping around.
    integer lo, hi;

    // Midpoint is computed combinationally; arithmetic shift keeps the sign.
    wire signed [31:0] mid;
    assign mid = (lo + hi) >>> 1;

    always @(posedge clk or posedge rst) begin
        if (rst) begin
            state <= IDLE;
            found <= 1'b0;
            index <= {IDX_W{1'b0}};
            done  <= 1'b0;
            busy  <= 1'b0;
            lo    <= 0;
            hi    <= 0;
        end else begin
            case (state)
                IDLE: begin
                    done  <= 1'b0;
                    busy  <= 1'b0;
                    found <= 1'b0;
                    index <= {IDX_W{1'b0}};
                    if (start) begin
                        lo <= 0;
                        hi <= N - 1;
                        if (N <= 0) begin
                            state <= FIN;
                        end else begin
                            busy  <= 1'b1;
                            state <= SEARCH;
                        end
                    end
                end

                SEARCH: begin
                    if (lo <= hi) begin
                        if (data_in[mid*WIDTH +: WIDTH] == key) begin
                            found <= 1'b1;
                            index <= mid;
                            state <= FIN;
                        end else if (data_in[mid*WIDTH +: WIDTH] < key) begin
                            lo <= mid + 1;
                        end else begin
                            hi <= mid - 1;
                        end
                    end else begin
                        state <= FIN;
                    end
                end

                FIN: begin
                    busy  <= 1'b0;
                    done  <= 1'b1;
                    state <= IDLE;
                end

                default: state <= IDLE;
            endcase
        end
    end

endmodule
