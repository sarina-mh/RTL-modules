# مرجع RTL میان‌ترم

کتابخانهٔ مستقل Verilog-2005 برای مرور و پیاده‌سازی الگوریتم‌ها. تست‌بنچ‌ها SystemVerilog هستند. تمام کامنت‌های RTL انگلیسی‌اند. فایل‌های پروژهٔ اصلی به این کتابخانه وابسته نیستند.

## فایل‌ها و ماژول‌ها

هر یک از ۸۴ ماژول در یک فایل جدا با اسم دقیق خودش داخل `rtl/` قرار دارد؛ برای مثال `selection_sort.v`، `fp_compare.v`، `fourier_series.v` و `fp16_divider.v`.

[فهرست کامل فایل‌ها و وابستگی‌های کامپایل](MODULE_INDEX.md)

[راهنمای امتحان، ۱۸ سورت و الگوریتم‌های رایج](STUDY_GUIDE.md) · [تیلور، exp، سری فوریه، DFT و FFT](NUMERICAL.md) · [گزارش تست](TEST_REPORT.md)

ماژول‌های `fp_compare`، `accumulator`، `mac`، `fp_arithmetic` و چهار wrapper مربوط به FP16 در همین مجموعه قرار دارند. محاسبات اعشاری binary16/binary32 هستند؛ مثال‌های تیلور و فوریه از fixed-point با قالب و بازهٔ مشخص استفاده می‌کنند.

## استفاده

هر ماژول را همراه فایل‌های وابستهٔ ذکرشده در فهرست کامپایل کنید؛ مثلاً `alu.v` به `add_sub.v` وابسته است. همهٔ فایل‌های `rtl/*.v` را نیز می‌توان همزمان کامپایل کرد. ماژول‌های FP16 این کتابخانه هم‌نام ماژول‌های پروژهٔ اصلی‌اند؛ این دو نسخه را در یک کامپایل قرار ندهید.

- پارامتر `W` عرض داده و `N` تعداد عناصر است. هر عنصر i در `data[i*W +: W]` قرار دارد. `N`، عمق حافظه و تأخیر pipeline باید حداقل یک باشند.
- ورودی `SIGNED=1` برای مقایسه، مرتب‌سازی و MAC معنای مکمل دو دارد. عرض ALU و جمع‌کننده پارامتری است. overflow و carry جدا هستند؛ carry تفریق یعنی بدون قرض.
- reset تمام مدارهای ترتیبی سنکرون و active-low است. حافظه‌های RAM و register file reset ندارند؛ پیش از خواندن نوشته شوند.
- الگوریتم‌ها start را هنگام بیکاری می‌پذیرند؛ دادهٔ ورودی همان موقع ذخیره می‌شود. done تک‌سیکل است. نتیجه هنگام done معتبر است و تا start بعدی حفظ می‌شود؛ حین busy روی خروجی‌های در حال محاسبه تکیه نکنید. ورودی start را یک سیکل فعال کنید.
- selection_sort در هر سیکل یک مقایسه و در سیکل جدا یک جابه‌جایی دارد. bubble_sort و insertion_sort هم چندچرخه‌ای‌اند. GCD مبتنی بر تفریق است و در بدترین حالت ممکن است طولانی شود.
- array_sum نمونهٔ کامل جداسازی کنترلر و دیتاپث است: `IDLE -> RUN -> REPORT`. در RUN هر سیکل یک عنصر جمع می‌شود. عرض پیش‌فرض جمع برای جلوگیری از overflow جمع unsigned انتخاب شده است.
- sequence_detector ورودی را MSB-first می‌خواند؛ `PATTERN` و طول `P` قابل تنظیم‌اند. hit_mealy قبل از لبهٔ مصرف آخرین بیت و hit_moore بعد از آن دیده می‌شود. OVERLAP انتخاب هم‌پوشانی را مشخص می‌کند.
- FIFO از نوع first-word fall-through است. در حالت پر، push همزمان pop پذیرفته می‌شود. در حالت خالی، push همزمان pop فقط داده را ذخیره می‌کند. RAM خواندن سنکرون read-first و register file خواندن آسنکرون دارد.

## Floating point

`fp_arithmetic` ترکیبی است: OP=0 جمع، OP=1 تفریق، OP=2 ضرب و OP=3 تقسیم. قالب پیش‌فرض E=5,F=10 همان binary16 است؛ E=8,F=23 برای binary32 استفاده شود. بازهٔ مجاز پیاده‌سازی: 3<=E<=8 و 2<=F<=23.

گرد کردن nearest-even، subnormal، صفر علامت‌دار، infinity و NaN پشتیبانی می‌شوند. NaN خروجی canonical و مثبت است. پرچم استثنا و rounding mode دیگر ارائه نشده‌اند. تقسیم از تقسیم صحیح significand استفاده می‌کند و ممکن است سخت‌افزار بزرگی بسازد؛ ثبت خروجی به معنای تضمین فرکانس کلاک نیست. synthesis، مساحت و timing اندازه‌گیری نشده‌اند.

`fp_stream` و چهار wrapper FP16 یک رجیستر خروجی با ready/valid دارند. ورودی وقتی `in_valid && in_ready` باشد روی لبه پذیرفته می‌شود؛ خروجی ثبت‌شده بعد همان لبه معتبر است و هنگام stall ثابت می‌ماند. از قالب stream برای اعمال backpressure استفاده کنید.

## اجرای تست

در ویندوز این سیستم:

```powershell
py midterm_reference/run_tests.py
py midterm_reference/check_lint.py
```

داخل پوشه، روی لینوکس با Verilator، GCC، make و Python:

```bash
python3 run_tests.py
python3 check_lint.py
```

مرجع floating-point با Fraction پایتون و گرد کردن دقیق ساخته می‌شود. تست‌ها شامل قالب کوچک exhaustive، همهٔ encodingهای binary16 در هر دو پورت با جفت‌سازی جایگشتی، بردارهای مرزی و تصادفی binary32، backpressure و reset هستند. این آزمون همهٔ ۲^۳۲ جفت ورودی FP16 را پوشش نمی‌دهد.

گزارش خلاصه در `results.json` و خروجی کامل کامپایل و شبیه‌سازی در `build/*.txt` نوشته می‌شود. تست‌بنچ‌های الگوریتمی نمونهٔ اجرای عملی ماژول‌ها هستند. فایل‌های build برای انتشار لازم نیستند؛ بردارها با اسکریپت دوباره ساخته می‌شوند.

پیش‌نیازها: Python 3.10+، Verilator 5.x، GCC و make. روی Windows مسیر پیش‌فرض MSYS2 برابر `C:\msys64` است؛ برای نصب دیگر، متغیر `MSYS2_ROOT` را تنظیم کنید. خود اسکریپت پایتون را در PowerShell با `py` اجرا کنید. روی Linux از `python3` استفاده کنید.

فقط یک بخش را نیز می‌توان اجرا کرد: `py run_tests.py --only sorting numerical`. برای ساخت ZIP نهایی، اجرای کامل هفت مجموعه و lint لازم است؛ سپس `py package_reference.py` را اجرا کنید.
